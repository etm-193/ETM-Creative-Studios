# ETM Creative Studios

> **Creating stories worth experiencing.**

Welcome to the official GitHub organization for **ETM Creative Studios**.

ETM Creative Studios is an independent creative studio dedicated to building immersive stories, interactive experiences, software tools, and games. This organization serves as the central hub for all development projects, documenting our journey from early prototypes to polished releases.

---

## 🎯 Mission

Our goal is simple:

> **Create meaningful experiences through technology and storytelling.**

Whether it's a tactical RPG, a productivity tool, or experimental AI software, every project is built with the same philosophy:

- Build with purpose.
- Learn continuously.
- Share the journey.
- Improve with every iteration.

## 📁 Repository Philosophy

Each major project is maintained in its own repository.

This allows every project to have:

- Independent version history
- Dedicated issue tracking
- Project-specific documentation
- Appropriate build configuration
- Technology-specific tooling
